# Override Exceptions

Packages we build ourselves although Fedora already ships them. Each row has a
matching `# Override Exception:` header in the spec; the rules are in
[spec-style-guide.md](spec-style-guide.md#10-override-exceptions). Remove a row
when its exit condition is met and the package is dropped.
